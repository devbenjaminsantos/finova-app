# Histórico de migrations SQL Server

Este diretório preserva as migrations usadas pelo Finova enquanto o banco ativo
era Azure SQL/SQL Server. Os arquivos estão fora do projeto da API e não são
compilados nem descobertos pelo Entity Framework.

Desde a migração para PostgreSQL, o diretório ativo é:

`server/FinanceDashboard.Api/Migrations`

Não aplique este histórico no Neon. Ele permanece apenas para consulta e para
rastreabilidade das decisões anteriores do schema.
